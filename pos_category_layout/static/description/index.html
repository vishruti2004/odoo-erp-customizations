POS Category Layout

Introduction

POS Category Layout enhances the Odoo POS interface with flexible category navigation, customizable layouts, and product display options. It allows administrators to configure category styles, sorting, search, hierarchy, colors, and grids separately for each POS configuration, providing a more organized and user-friendly experience.

Key Features

1. Comprehensive POS Configuration

Manage category layout preferences directly from the POS configuration. Configure the category position, layout style, card appearance, category visibility, sorting, navigation, breadcrumbs, visible rows, scrolling direction and pagination options. The selected settings are applied to the corresponding POS configuration.

2. Flexible Category Layouts

Choose from supported category layouts, including horizontal top bar, sidebar and popup navigation. Configure the sidebar position according to the required POS screen arrangement.

3. Category Card Customization

Select the available category card styles and configure the display of category images and names. Customize category presentation using the supported card options.

4. Grid, List and Nested Categories

Organize categories using supported grid or list layouts. Navigate parent and child categories, expand or collapse nested categories, and move between category levels easily.

5. Category Search and Quick Access

Find categories by name using the category search option. Access categories through the available navigation controls and use the category popup for convenient browsing.

6. Category Visibility and Sorting

Configure the category browsing scope to show the main categories or include all categories. Arrange categories using the available sorting and ordering options.

7. Breadcrumbs and Category Counts

Use breadcrumb navigation to identify the current category path. Where supported, display product counts on category cards to provide a quick overview of category contents.

8. Scrolling, Rows and Pagination

Configure the number of visible category rows and the supported scrolling direction. Use available scrolling or pagination controls to navigate larger category collections efficiently.

1. Configuration

Open Point of Sale → Configuration and select the required POS configuration. Enable Enable Custom Category Layout to access the additional category configuration options. Once enabled, all available category layout and navigation settings can be configured from the same section.

Configuration Flow: Open POS Configuration  →  Enable Custom Category Layout  →  Configure the available options  →  Save

Configuration Options

Enable Enable Custom Category Layout to display the additional settings. Configure the category display position, card style, visibility content, image position and category scope. Additional options include category sorting, breadcrumbs, product counts, search, background colors, the Show All Categories button, font family, visible rows, pagination and scroll direction. Save the configuration to apply the selected preferences to the corresponding POS session.

2. Category Layouts

The POS Category Layout module provides multiple ways to display product categories in the Point of Sale interface. Choose the layout that best suits your workflow and screen arrangement. The available layouts include Top Bar, Sidebar and Popup.

Top Bar Layout

Display categories in a horizontal navigation bar at the top of the POS screen. Users can select a category directly from the bar to browse its associated products.

Sidebar Layout

Display categories vertically along either the left or right side of the POS screen. Select the sidebar position according to the preferred screen arrangement while keeping category navigation accessible.

Right Sidebar

Popup Layout

Display category navigation inside a popup window when the user opens the category selector. Users can browse the available categories in the popup and select the required category before returning to the POS interface.

3 .Category Card Customization

The category display settings control how category names and images appear on the POS screen. Select the required option in the POS configuration to display categories according to the selected presentation style and image position.

Name

When Name is selected in the category configuration, the category is displayed using its name on the POS screen.

Cover Image

When Cover Image is selected, the category is displayed using the cover-image presentation on the POS screen.

Top

When Top is selected as the image position, the category image appears above the category name.

Bottom

When Bottom is selected as the image position, the category image appears below the category name.

Available Options

Select the desired category display option in the POS configuration. The available options include Name, Cover Image, Top, Bottom, Left and Right, depending on the selected configuration field. The selected option determines how the category name and image are presented on the POS screen.

4. Category Navigation Styles

The Sidebar layout provides two category navigation styles: Grid Card and Nested List. Select the required style in the POS configuration to control how categories are organized and displayed in the sidebar.

Grid Card

When Grid Card is selected, categories are displayed as individual cards in a grid-style arrangement within the sidebar layout. This provides a visual way to browse and select categories.

Nested List

When Nested List is selected, categories are displayed in a hierarchical list. Parent categories and their child categories can be viewed according to the available navigation behavior.

Note

The Grid Card and Nested List options become available when the Sidebar layout is enabled in the POS configuration. The selected option determines how categories are displayed in the POS interface.

5. Category Search and Quick Access

Quickly find categories using the category search bar. Search results include matching categories and subcategories, making it easier to locate the required category without navigating through each parent category manually.

Category Search Bar

Enter a category name in the search bar to quickly find the required category.

Search Results Including Subcategories

Matching subcategories also appear in the search results, allowing users to find and access them directly without manually opening each parent category.

All Categories Button

Use the All Categories button to quickly access the available product categories in the POS interface. Clicking the button displays the category list, allowing users to browse and select the required category.

All Categories Button

All Categories Result

View the available categories and select the required category directly from the displayed list.

6. Category Visibility and Sorting

Configure category sorting in the POS settings. The default Odoo sorting behavior is retained, and an additional A to Z sorting option is available to arrange categories alphabetically. Users can choose the sorting method according to their preference.

Category Sorting Configuration

Select the default Odoo sorting behavior or choose the additional A to Z option to display categories in alphabetical order.

Categories Sorted A to Z

When A to Z sorting is selected, categories are displayed in alphabetical order for easier browsing.

7. Breadcrumbs and Category Counts

Use breadcrumb navigation to identify the current category path. Where supported, product counts on category cards provide a quick overview of the products available in each category.

Breadcrumbs and Category Counts Configuration

Review the available configuration options for breadcrumb navigation and category product counts.

Breadcrumb Navigation and Category Counts Result

Breadcrumbs show the current category path, while category counts provide a quick overview of the products available in each category.

8. Scrolling, Rows and Pagination

Configure the number of visible category rows and the supported scrolling behavior. Navigate larger category collections using pagination controls or the available scrollbar for convenient browsing.

Scrolling and Pagination Configuration

Configure the available category row, scrolling and pagination settings.

Category Pagination Result

Navigate between category pages using the available pagination controls when displaying a large number of categories.

Category Scrollbar Result

Browse additional categories by scrolling through the category area using the available scrollbar.

Face Recognition Attendance

Enhance Odoo Attendance with camera-based Check In / Check Out, face recognition, live face verification, attendance image capture, location-based validation and anti-spoofing protection.

Key Features & Capabilities

Camera-Based Attendance

Camera-based Check In and Check Out with browser permission handling and attendance image capture.

Face Recognition

Employee face registration, automatic or manual face encoding, and identity verification.

Live Face & Anti-Spoofing

Live face detection and anti-spoofing validation help prevent attendance fraud using printed photos or digital screens.

Location-Based Validation

Validate attendance using configured latitude, longitude, radius, and authorized physical locations.

Backend & Kiosk Support

Face recognition support seamlessly integrated into backend administrative processing and dedicated Attendance Kiosk workflows.

Attendance Image Storage

Store Check In and Check Out facial captures directly alongside the corresponding attendance record for easy auditability.

Multiple Attendance Locations

Configure multiple geo-fenced locations complete with company-wise assignment rules and access settings.

Flexible Attendance Options

Configure granular, employee-wise options (e.g., standard check-in vs. mandatory facial recognition or image capture).

Attendance Configuration & Setup

Configure the required attendance settings before using camera capture, face recognition, kiosk attendance, and location-based validation.

1. Employee Face Registration

Add the employee face image that will be used for face recognition and attendance verification.

2. Attendance Settings

Go to Attendances → Configuration → Settings and configure the required attendance modes, camera capture, face recognition, kiosk support, and location tracking options.

3. Face Attendance Location

Go to Attendances → Configuration → Face Attendance Locations and configure the authorized location using latitude, longitude, radius, and company.

Attendance with Camera Capture

Enable camera-based attendance to capture the employee image during Check In and Check Out.

The system checks browser camera permission, displays a live camera preview, captures the image, and records the attendance.

Camera Permission → Camera Preview → Capture Image → Attendance

1. Camera Permission

The browser requests camera permission before capturing the employee image.

2. Camera Preview

After permission is granted, the live camera preview is displayed for image capture.

3. Successful Check-In

The system confirms that the attendance has been successfully updated after image capture.

4. Attendance Record

The newly created attendance record is displayed in the Attendance list with the Check In details.

Anti-Spoofing & Live Face Verification

The system validates whether the detected face belongs to a real person before allowing attendance. This helps prevent attendance using photos or other non-live face sources.

Live Face Detection → Anti-Spoofing Validation → Face Verification → Attendance

1. Live Face Verification

The camera captures the face and performs live face validation before attendance.

2. Spoof Detection

If a non-live face is detected, the system rejects the attendance and displays a spoof detection message.

Face Recognition Kiosk

The dedicated Kiosk Mode allows employees to perform Check In and Check Out using camera-based face recognition without accessing the regular Odoo backend.

The kiosk captures the employee face, verifies the identity, and records the attendance through the configured face recognition workflow.

Kiosk Mode → Face Capture → Face Recognition → Check In / Check Out

1. Kiosk Mode

Employees can select Face Recognition directly from the dedicated Kiosk screen.

2. Face Recognition

The Kiosk camera captures and verifies the employee face for attendance.

3. Attendance Confirmation

After successful face verification, the employee attendance is recorded through the Kiosk.

Location-Based Attendance

Location-based attendance ensures that employees can Check In and Check Out only from authorized attendance locations configured by the administrator.

Location Permission → Current Location → Latitude / Longitude Validation → Radius Check → Attendance

1. Configure Attendance Location

Go to Attendances → Configuration → Face Attendance Locations to configure authorized attendance locations using Latitude, Longitude, and allowed Radius.

2. Location Validation Failed

If the employee is outside the configured attendance area, the system prevents attendance and displays a location validation error message.

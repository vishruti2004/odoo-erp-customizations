# Split View Module for Odoo 19

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0.html)

**Free & open-source · Display list and form view side by side**

Maintained by **[Albirru Solutions](https://www.albirru.com/)**.

The Split View module enhances your Odoo experience by allowing you to view list or kanban views side-by-side with form views. This eliminates the need to constantly switch back and forth between views, significantly improving data entry and review speed.

## Features
- **Toggle split view mode**: Easily switch split view on/off in list and kanban views.
- **Resizable split panel**: Drag the separator to resize panels to your preference.
- **Auto-save**: Automatically saves changes when navigating to another record.
- **Persistent Preferences**: Remembers your split position and state.
- **Keyboard Navigation**: Fully supports keyboard shortcuts and pager navigation.
- **Close Button**: Quickly close the split view to return to full list mode.

## Usage
1. Navigate to any list or kanban view.
2. Click the **Split View** button in the control panel (panel icon).
3. Click on any record to open it in the side panel.
4. Drag the separator to resize panels.
5. Click the **X** button or toggle button to close split view.

## Installation
- Install the module normally via Odoo Apps.
- No additional configuration required.
